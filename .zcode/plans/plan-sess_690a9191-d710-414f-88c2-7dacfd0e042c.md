## 现状

`SubscriptionsView.vue`、`CollectionsView.vue`、`FilesView.vue` 三个页面的"新增/编辑"表单目前都是页面顶部常驻的一张卡片（内嵌 `PipelineEditor`、`CodeEditor`、`PreviewPanel`），编辑态与新建态共用同一块区域，通过 `editingId`/`editing` 是否为空切换标题和按钮文案。这次要把这块表单区改成弹出对话框，列表和分享设置弹窗（`ShareDialog`）不变。

`ShareDialog.vue` 已经是一个手写的弹窗（`fixed inset-0` 遮罩 + 居中面板），但没有 Escape 关闭、没有抽出复用组件。为了不重复三份几乎一样的遮罩/面板/关闭逻辑，新增一个共享的弹窗外壳组件，`ShareDialog` 本次不动（不在需求范围内，改了增加不必要的风险）。

## 新增组件：`frontend/src/components/ModalDialog.vue`

复用 `ShareDialog` 已验证过的视觉结构（遮罩 `bg-slate-900/50`、居中面板 `bg-surface rounded-xl shadow-2xl`、`px-4 sm:px-6` 内边距），做成通用外壳：

```
Props: open: boolean, title: string, subtitle?: string, maxWidth?: string（默认 'max-w-2xl'）
Emits: close
Slots: default（正文）, footer（可选，本次三个新弹窗不使用，正文里已含操作按钮，与现状保持一致）
```

行为：点遮罩关闭、点 X 关闭、新增 Escape 关闭（`ShareDialog` 目前没有，这是唯一比现状多出的交互，风险很低）。不做焦点陷阱、不锁背景滚动——与 `ShareDialog` 现有的复杂度对齐，不额外引入新的交互模型。

## 预览面板的处理方式

三个页面现在的 `<PreviewPanel>` 挂载点服务两种场景：表单内"即时预览"当前草稿、列表行"预览"已保存项。这次只改"新增/修改"，预览行为不变，所以：

- 页面级 `<PreviewPanel>` **原位置保留**，继续服务列表行的"预览"点击（这个按钮不移进弹窗，行为完全不变）。
- 弹窗内部**新增第二个** `<PreviewPanel>` 实例，服务弹窗内"即时预览"按钮（因为遮罩是 `fixed inset-0`，页面级面板会被盖住看不见）。两者共享同一个 `usePreviewStore`，关弹窗时调用 `preview.close()` 清空结果，避免草稿预览的残留内容在关闭后显示在页面级面板上。

## 三个页面的改动（结构一致，逐个应用）

**`SubscriptionsView.vue`**
- 头部加"+ 新建订阅"按钮（`订阅管理` 标题右侧，此前拉取合并按钮已删除，位置空着）。
- 原表单卡片（字段网格 + `PipelineEditor` + Save/预览/取消按钮）整体移入 `<ModalDialog :open="dialogOpen" :title="editingId !== null ? '编辑订阅' : '新建订阅'" max-width="max-w-3xl">`，去掉卡片内重复的 `<h2>` 标题。
- 新增 `dialogOpen` ref、`openCreate()`（重置表单后打开）；`onEdit` 末尾追加 `dialogOpen.value = true`；新增 `closeDialog()`（关闭 + 重置表单 + 清空预览），`onSave` 成功后调用 `closeDialog()` 替代原来的 `resetForm()`；"取消编辑"按钮改调 `closeDialog`。
- 列表行"编辑"/"预览"按钮：编辑走上面的 `onEdit`（现在会带开弹窗），"预览"保持调 `onPreviewSaved`，不变。

**`CollectionsView.vue`**
- 目前没有页面级标题栏，新增一行"组合订阅" + "+ 新建组合"按钮。
- 同样把表单卡片整体移入 `ModalDialog`（`max-width="max-w-3xl"`），去掉内部 `<h2>`。
- `startEdit` 追加开弹窗；新增 `openCreate`/`closeDialog`；`save()` 成功后调 `closeDialog()`；"取消编辑"改调 `closeDialog`。

**`FilesView.vue`**
- 新增标题栏"文件托管" + "+ 新建文件"按钮。
- 表单卡片（字段较多，含条件性的模板/远程/合并选项）移入 `ModalDialog`（`max-width="max-w-4xl"`，字段最多需要更宽），说明性段落保留在弹窗正文里。
- `onEdit` 追加开弹窗；新增 `openCreate`/`closeDialog`；`onSave` 成功后调 `closeDialog()`；"取消编辑"改调 `closeDialog`。

## 不改动的部分
- 后端：零改动，纯前端交互/布局调整。
- `ShareDialog.vue`：不改，继续保持独立弹窗，与新弹窗互不影响（两者可能同时挂载但不会同时触发）。
- 列表展示、分享链接、同步、删除等既有逻辑：不变。
- 预览的触发条件和校验逻辑（`validate()`、`onPreview()`/`onPreviewSaved()`）：不变，只是渲染位置多了一份。
